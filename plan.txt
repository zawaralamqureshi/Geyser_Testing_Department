1. Goal
-------
- Protocol-aware Python tool: read CLK + RAW from D:\Electrical_tests\Cells and Blocks\
  (paths configurable), parse headers and step tags, detect protocol, ingest CLK metrics,
  optional full RAW → BigQuery time_series, boundary-based ESR for selected protocols,
  Looker-friendly curves (CYCLING + CV/SNU; no dQ/dV), upload to BigQuery, optional GCS
  staging, per-table fingerprints, smart skip, Tkinter GUI + CLI, Looker dashboards.

- Trigger: Tkinter “Update BigQuery” or CLI (--upload, --stage-only, --upload-batch, ...).


2. Paths, IDs
-------------
- Primary: Object: header + YYMMDD patterns → index_id, date_ymd, group_id, test_date.
- Folder layouts flexible; tool does not require strict YYYY\MM\DD\N_Gnn\NNN.


3. Step tags
------------
- Mapped in clk_reader STEP_TYPE_MAP → canonical step_type (CCC, DISCHARGE_CC, SCAN_V,
  RELAX, …). RAW reader aligns Step column with same mapping.


4. Protocol detection
---------------------
- Labels in BQ test_runs.protocol_detected: STANDARD_CELL, BLOCK_SCANNING, BLOCK_CYCLING,
  CYCLABILITY, UNKNOWN. CYCLABILITY evaluated before YAML registry; registry.yaml defines
  keyword rows; detector.py has fallbacks.


5. Metrics
----------
5.1 CLK — trusted per-step + GNRL (capacity, energy, ESR fields from cycler, efficiencies, …).

5.2 ESR from RAW (implemented 2026)
- Boundary method in geyser_tool/analysis/esr.py.
- Runs only if protocol_detected is STANDARD_CELL, BLOCK_CYCLING, or CYCLABILITY AND
  program text matches a 1 s rest (Rest 1s, Rest during 1s, patterns in program_has_rest_1s).
- Each DCC/DCCC/DCHCC segment immediately followed by RLX/RLAX: last discharge V and |I|;
  delay_s ~0.01 → first RLX voltage; delay_s 1.0 → last RLX voltage; esr_ohm = (v_at - v_end) / |I|.
- esr.strict_mode / tolerance_s do not affect this path; delays still from esr.delays_s.

5.3 Curves — downsampled from in-memory time_series rows; per (cycle_no, step_no) by default;
  CV segment caps; no dQ/dV.


6. BigQuery tables
------------------
- test_runs, cycle_metrics, step_metrics, time_series (full RAW), esr_computed, curves,
  run_fingerprints.


7. Architecture (key modules)
-----------------------------
- geyser_tool/config.py, pipeline.py, ids.py
- parsers: header, clk_reader, raw_reader
- protocol: detector.py, registry.yaml, program_model.py
- analysis: esr.py, curves.py
- upload: bigquery.py, staging.py, fingerprint.py
- gui/app.py, cli/main.py
- scripts/setup_bigquery.py, migrate_* as needed

(There is no sniffer.py in the current tree; tests/ and PyInstaller scripts are optional
 ad hoc, not a committed test suite or shipping artifact.)
