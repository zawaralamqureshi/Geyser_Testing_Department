1. Purpose
----------
Windows-oriented Python tooling for **Geyser** (ASK75 / ACK75) electrical
cycler data. It:

  - Finds `*-CLK.txt` files under configurable **Cells** and **Blocks** roots.
  - Parses analyzer headers (**Object:**, **Program:**, metadata).
  - Classifies **`protocol_detected`** from program text (+ YAML registry +
    Python rules for CYCLABILITY).
  - Loads **trusted** cycle/step metrics from CLK into BigQuery.
  - Optionally discovers companion **RAW** files, builds **`time_series`**
    (full sample rate — no downsampling), **`curves`** (Looker-sized
    downsampling), and **`esr_computed`** (boundary-based ESR from RAW when
    gates pass).
  - Stages columnar **Parquet** locally; optionally uploads to **GCS** and
    **loads BigQuery**; maintains **per-table fingerprints** so unchanged runs
    can skip reprocessing unless forced.

Triggers: **`python -m geyser_tool.cli.main`** with paths and flags, or
**`python -m geyser_tool.gui.app`** (Tkinter) for browse / stage / upload.

3. End-to-end flow (one CLK run)
---------------------------------
1. **Discovery** — Recurse directories (or explicit paths) for `*-CLK.txt`.
2. **Header / program** — Read metadata; program lines → `ProgramStep` list
   (today **`step_num`** + **`mode`** strings; richer `params` / `cycle_ref`
   are not fully populated).
3. **Protocol** — Uppercase modes, join text, run `detect_protocol()` → value
   stored on **`test_runs.protocol_detected`**.
4. **IDs** — Derive **`index_id`**, **`entity_type`** (**cell** / **block**),
   **`date_ymd`**, **`group_id`**, **`test_date`**. **`entity_type`** comes from
   path/object patterns, **not** from protocol name.
5. **Fingerprints** — Per-table fingerprints from file paths, sizes, mtimes.
   Compared to **`run_fingerprints`** in BigQuery. All match ⇒ skip unless
   **`--force`** or **`--force-run <run_id>`**.
6. **CLK metrics** — Tabular **`GNRL`** and per-step rows → **`cycle_metrics`**,
   **`step_metrics`**; aggregates for charge/discharge capacity and energy where
   applicable.
7. **RAW** (unless **`--no-raw`**) — Sibling RAW files parsed; stitched
   **`time_series`**; optional synthetic gap **`raw_ts.inter_cycle_gap_s`**
   between RAW files on global **`time_s`** (default **0**).
8. **ESR** — If protocol + program rest-phrase gates pass, **`esr_computed`**
   rows from discharge→relax boundaries (see §6).
9. **Curves** — Downsampled from in-memory trajectory for dashboards; default
   is per **`(cycle_no, step_no)`** segment (**`curves.curves_per_step_segment`**).
10. **Output** — Parquet batch under **`paths.staging_root`**; upload to GCS if
    **`gcs.gcs_bucket`** set; **`LOAD`** into dataset **`bq.dataset`**; upsert
    fingerprints.


4. Inputs: CLK and RAW layouts
-------------------------------
Paths default under **`D:\Electrical_tests\`** (`Cells`, `Blocks`, `_staging`);
override in **`paths.*`** in config.

**CLK** — One summary file per test object channel run; naming `*-CLK.txt`.

**RAW** — Per-cycle ASCII tables; discovery differs slightly:

  - **Blocks (ACK75.48)** — Often under a **`RAW/`** subfolder beside the CLK
    numbering folder.
  - **Cells (ACK75.10)** — Often under **`{object_id}-RAW/`**.

The RAW reader aligns **`Step`** markers with the same canonical **`step_type`**
concept as CLK (see **`clk_reader.STEP_TYPE_MAP`** and RAW reader).


5. Canonical step tags (concept)
----------------------------------
ASK/ACK step markers (**CHCC**, **DCCC**, **SNU**, **RLAX**, …) map to a smaller
set of **`step_type`** values (**CCC**, **DCC**, **SCAN_V**, **RELAX**, …) for
downstream logic and BigQuery columns. Full mapping lives in code, not here.


6. Protocol detection (**`test_runs.protocol_detected`**)
------------------------------------------------------------
Emitted values are **exactly**:

  **`CYCLABILITY`**, **`STANDARD_CELL`**, **`BLOCK_SCANNING`**,
  **`BLOCK_CYCLING`**, **`UNKNOWN`**

**Deterministic order** (see **`Tool/geyser_tool/protocol/detector.py`**):

1. **CYCLABILITY** — Evaluated **before** **`registry.yaml`**. Separate **cell**
   vs **block** branches using **`Discharge CC`** (correct) vs typo
   **`Discarge CC`**; cycle count thresholds use **strict `>` 20** (e.g.
   **`Preset number of cycles: N`** with **N > 20** on blocks; analogous logic on
   cells with **`Cycle to step … <n> times`**). Confidence typically **0.5**.

2. **YAML registry** — Rows in **`geyser_tool/protocol/registry.yaml`** in file
   order (**`keywords_all`**, **`keywords_any`**, optional **`min_steps`**).

3. **Fallback heuristics** — If YAML missing or nothing matches.

Changing **BLOCK_\*** keywords: edit **`registry.yaml`**. Changing **CYCLABILITY**
thresholds/shape: edit **`detector.py`**.

Historical SOP names (**VTT_TEST1_BLOCK**, **REFERENCE_GCD**, **VTT_FCRD_NONZINC**,
**DCIR_SOC**, …) are **not** emitted labels — see archived **§3B** in the long
plan; some align with permanently out-of-scope items.


7. Trusted CLK metrics (**`cycle_metrics`**, **`step_metrics`**)
------------------------------------------------------------------
 CLK already contains capacities, energies, cycler-derived ESR fields,
 efficiencies, durations, etc. These are ingested **as-is** — the tool does not
 recompute **`Q,Ah`**, **`E,Wh`**, **`C,F`**, **`ER*,mR`**, **`ESR,mR`** for
 warehousing (boundary ESR is a **parallel** **`esr_computed`** pathway).


8. RAW time axes and **`time_series`**
---------------------------------------
Within one RAW file, **`Time,s`** resets at each **`Step`** change. The reader
computes **`time_continuous_s`** by summing **`max(Time,s)`** over contiguous runs
of the same step marker so physical duration matches the table.

Across multiple RAW files (cycles) stitched for one CLK, BigQuery **`time_series.time_s`**
extends that axis; **`raw_ts.inter_cycle_gap_s`** adds an optional synthetic gap
between files (default **0**; e.g. **0.01** s if you want a visible delimiter).


9. Boundary ESR (**`esr_computed`**)
--------------------------------------
Implemented in **`geyser_tool/analysis/esr.py`**. Rows exist only when:

  - **`protocol_detected`** ∈ { **`STANDARD_CELL`**, **`BLOCK_CYCLING`**,
    **`CYCLABILITY`** }, **and**
  - joined program text matches a **1 s rest** pattern (e.g. **`Rest 1s`**,
    **`Rest during 1s`**, helpers in **`program_has_rest_1s`**).

For each RAW segment labelled **discharge** (**DCC**, **DCCC**, **DCHCC**)
followed contiguously by **RLX / RLAX**:

  - **`delay_s` ≈ 0.01** — **`v_at_delay_v`** = **first** voltage sample on the
    relax step; **`v_end_v`** = **last** discharge voltage; **`esr_ohm`** =
    (**`v_at_delay_v`** − **`v_end_v`**) ÷ |**I**| from last discharge row.
  - **`delay_s` = 1.0** — **`v_at_delay_v`** = **last** relax voltage (~1 s end).

Multiple pairs per RAW file when the sequence repeats.

**`esr.strict_mode`** and **`esr.tolerance_s`** **do not** affect this pathway;
they are legacy knobs. **`esr.delays_s`** selects which delay columns (**0.01**
and/or **1.0**) appear.


10. **`curves`** table (Looker-facing)
--------------------------------------
Built from the same RAW trajectory but **downsampled**. Default mode: one budget
per **`(cycle_no, step_no)`** (**`curves_per_step_segment: true`**) so step
boundaries survive for Cycling + CV charts. CV segments have separate caps,
including tighter limits when **`sample_rate_hz`** is low (see **`curves.py`**
and config). **No dQ/dV.**

**Full fidelity remains in `time_series`.** Tune chart density under **`curves:`**
in **`config.yaml`**; see **`Tool/config.example.yaml`** for all keys.


11. Fingerprints and smart skip
---------------------------------
**`run_fingerprints`** stores one fingerprint per (**`run_id`**, **`table_name`**).

Fingerprints derive from RAW/CLK **file metadata** (paths, mtimes, sizes), not a
full file hash of contents. **`--force`** ignores all skips; **`--force-run`** can
target specific runs.

Staged batches include **`run_fingerprints.json`** for deferred **`--upload-batch`**.


12. Staging, GCS, BigQuery loads
--------------------------------
  - **`--upload`** — Full path: process → Parquet staging → optionally GCS →
    BigQuery load + fingerprint upsert.
  - **`--upload --stage-only`** — Writes **`batch_YYYYMMDD_HHMMSS`** under
    **`paths.staging_root`** with **`*.parquet`**, **`run_ids.txt`**,
    **`run_fingerprints.json`** — no cloud upload.
  - **`--upload-batch <folder>`** — Consume that batch folder; deletes existing
    BigQuery rows for listed **`run_ids`** then reloads (idempotent correction
    workflow).

If **`gcs.gcs_bucket`** is empty, loaders can stream from memory / local
Parquet without GCS (**`staging.py`** / **`bigquery.py`**).


13. BigQuery tables (conceptual)
---------------------------------
| Table            | Role |
|------------------|------|
| test_runs        | One row per processed CLK — metadata, protocol, ids, paths |
| cycle_metrics    | Per-cycle (**GNRL**) metrics |
| step_metrics     | Per-step CLK metrics |
| time_series      | Full RAW samples (all points) |
| curves           | Downsampled Cycling + CV traces for charts |
| esr_computed     | Boundary ESR from RAW where gated |
| run_fingerprints | Skip / change detection |

Dataset default **`electrical_tests`**; project from **`bq.project`** (see
 **`setup_bigquery.py`** migrations for additive columns).


14. CLI (summary)
-----------------
Run from **`Tool/`**: **`python -m geyser_tool.cli.main [--config PATH]`**

  - **paths** — CLK files or directories (unless **`--upload-batch`** only).
  - **`--upload`** — Enables BigQuery-oriented processing.
  - **`--stage-only`** — With **`--upload`**: Parquet batch only.
  - **`--upload-batch DIR`** — Load an existing staged batch.
  - **`--no-raw`** — CLK only (no **`time_series`**, no RAW-derived curves/ESR).
  - **`--dry-run`** — Process without cloud upload (direct upload flow).
  - **`--force`**, **`--force-run RUN_ID`** — Fingerprint overrides.

Full table: **`Tool/README.md`**.


15. GUI (summary)
-----------------
**`python -m geyser_tool.gui.app`**

Rough alignment with CLI: browse folder, scan headers, **Stage to Parquet**,
**Upload batch…**, **Update BigQuery**, **Force re-upload** checkbox.


16. Configuration reference (**`Tool/config.yaml`**)
------------------------------------------------------
Structured sections (**not** legacy flat **`bigquery_project`** keys):

  - **`paths`** — **`cells_root`**, **`blocks_root`**, **`staging_root`**
  - **`bq`** — **`project`**, **`dataset`**, **`service_account_key`** (optional;
    ADC if null)
  - **`gcs`** — **`gcs_bucket`**, **`gcs_staging_prefix`**
  - **`esr`** — **`delays_s`**, **`strict_mode`**, **`tolerance_s`**
  - **`raw_ts`** — **`inter_cycle_gap_s`**
  - **`curves`** — per-step caps, CV low-rate tuning, legacy whole-cycle mode
    when **`curves_per_step_segment: false`**

Root **`object_to_index_regex`** — pattern for extracting **`index_id`** parts.

Defaults and comments: **`Tool/config.example.yaml`**; dataclass defaults:
 **`geyser_tool/config.py`**.
